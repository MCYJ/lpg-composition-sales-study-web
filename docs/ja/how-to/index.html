使い方

  1. 組成の基準を選びます。同じ数値を別の基準に切り替えると解釈も変わります。
  2. 割合と合計molを入力し、適用ボタンで現在ケースを保存します。未適用の編集は図に反映しません。
  3. 合計値と1mol当たりの値を分けて読みます。原子数の収支で式を照合します。
  4. AとBは別々の保存ボタンで更新します。読み込み後も、もう一方の保存条件を維持します。

学習記録、ブックマーク、設定と保存A/Bは端末内の保存です。アプリ削除や端末変更前に必要な情報を確認してください。選択したローカル通知はOSの許可と予約機能を使い、初期状態では通知に問題文を表示しません。
