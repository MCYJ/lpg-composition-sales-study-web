学習ガイド

01 / CONCEPT

割合の基準を選ぶ

モル割合は成分のmol÷合計mol、質量割合は成分質量÷合計質量です。入力前に基準を選びます。基準の切り替えは同じ数値を新しい基準で解釈する操作で、自動換算ではありません。

02 / CONCEPT

二つの成分を区別する

模型はC3H8とC4H10だけを含みます。入力したプロパン割合の残りをブタンとし、他の成分は扱いません。実際の製品を測定したり、液相と気相の組成が同じだと判定したりする機能ではありません。

03 / CONCEPT

近似モル質量を明示する

教育用の固定値44g/molと58g/molを使います。質量割合wからモル割合xへの換算は(w/44)/(w/44+(1-w)/58)です。これらは精密な物性測定値ではありません。

04 / CONCEPT

反応式の係数を読む

C3H8+5O2→3CO2+4H2Oと2C4H10+13O2→8CO2+10H2Oを仮定します。各成分のmolに係数を掛けて合計します。理論上の係数は、バーナーや空気供給の設定値ではありません。

05 / CONCEPT

元素の収支を照合する

反応前後のC・H・O原子の物質量を照合します。1molのH2Oは水分子の量であり、H原子2molとO原子1molを含みます。表示した水のmolを、そのまま気体体積や凝縮水の体積に置き換えないでください。

06 / CONCEPT

50mol%の2molを読む

独自例はプロパン1molとブタン1molです。O2は11.5mol、CO2は7mol、H2Oは9molになります。模型質量は44gと58gなので、プロパン質量割合は44/102、約43.14%です。

07 / CONCEPT

50質量%との違いを見る

別の1mol独自例は50質量%のプロパンです。モル割合は29/51、約56.86%、1mol当たりO2は約5.647molです。50mol%の5.750molと区別し、成分比を実際の燃料の優劣として解釈しません。

08 / CONCEPT

1mol基準で比較する

A/Bの合計molが違うときは、合計O2の差だけでは組成と試料サイズを区別できません。合計と1mol当たりの値を別々に示します。B-Aの正負は数量の差で、性能・安全性・適否を判定しません。

09 / CONCEPT

現在ケースとA/Bを分ける

適用操作は現在ケースを保存します。A/Bは各保存ボタンで独立して更新し、未適用の入力は図に使いません。読み込みは保存した条件を現在ケースへ戻します。端末内保存で、アカウント同期や運営者の復旧機能はありません。

10 / CONCEPT

模型の外にあることを確認する

気液平衡・容器挙動・空気設定・過剰空気・流量・発熱量・CO/排出・換気・現場施工・法令適合・公式採点は扱いません。公式試験の全範囲や合格を保証せず、試験情報は公式案内で確認します。
